    About this tool

    Is this a diagnosis?

    No. It is a machine-learning prediction that can be wrong or incomplete. It never replaces an assessment by a qualified professional.

    What does the score mean?

    The model returns one number. Its scale and direction are not defined in the API, so this page does not interpret it.

    How accurate is it?

    No accuracy or clinical validation figures were provided, so none are shown.

    Where do my answers go?

    To the API address set in script.js. This page does not save them. Ask whoever hosts the server how requests are logged.
